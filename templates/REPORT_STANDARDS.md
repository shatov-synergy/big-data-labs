# Стандарты оформления отчётов по лабораторным работам
## Университет «Синергия»

> Стандарты извлечены из утверждённых отчётных документов обучающегося
> (отчёты по лабораторным работам и выпускная квалификационная работа).
> Этот файл — единый источник правил: по нему нейросеть собирает docx-отчёт
> по любому заданию без просмотра примеров.

---

## 1. Параметры страницы

| Параметр | Значение |
|---|---|
| Формат | A4 портрет (21 × 29,7 см) |
| Поля | верх 2 см, низ 2 см, **лево 3 см**, право 1,5 см |
| Колонтитулы | 1,25 см |
| Нумерация страниц | не используется в лабораторных отчётах |

## 2. Шрифты и абзацы (клон стиля ВКР)

| Элемент | Шрифт | Размер | Начертание | Прочее |
|---|---|---|---|---|
| Обычный текст | Times New Roman | 14 пт | обычный | полуторный интервал, по ширине, красная строка 1,25 см (ГОСТ 7.32-2017 / методичка) |
| Заголовок 1 (раздел) | Times New Roman | 16 пт | полужирный | по центру, с новой страницы, одинарный интервал, без красной строки |
| Заголовок 2 (подраздел) | Times New Roman | 14 пт | полужирный | по центру, одинарный интервал, без красной строки |
| Заголовок 3 | Times New Roman | 14 пт | полужирный | слева, одинарный интервал |
| Подпись рисунка | Times New Roman | 14 пт | **полужирный** | по центру, одинарный интервал |
| Подпись таблицы | Times New Roman | 14 пт | **полужирный** | см. раздел 5, одинарный интервал |
| Код программы | Courier New | 10 пт | обычный | одинарный интервал, фон #F2F2F2, без красной строки |
| Вывод среды R | Courier New | 10 пт | обычный | одинарный интервал, без фона |
| Текст в таблицах | Times New Roman | 12 пт | шапка полужирная | одинарный интервал, ячейки по центру/слева, границы одинарные |

## 3. Титульный лист (форма Синергии, клон образца)

Всё — Times New Roman, одинарный интервал, по центру. Метки — полужирные,
значения — **подчёркнутые**, под каждой формой-строкой подсказка 9 пт.

```
НЕГОСУДАРСТВЕННОЕ ОБРАЗОВАТЕЛЬНОЕ ЧАСТНОЕ УЧРЕЖДЕНИЕ   (полужирный, 14)
ВЫСШЕГО ОБРАЗОВАНИЯ «МОСКОВСКИЙ ФИНАНСОВО-ПРОМЫШЛЕННЫЙ
УНИВЕРСИТЕТ «СИНЕРГИЯ»»                                 (полужирный, 14)

Факультет: _Информационных технологий_                  (метка полужирная, значение подчёркнуто)
        (наименование факультета / института)           (9 пт)

Направление подготовки: _09.03.02 Информационные системы и технологии_
      (код и наименование направления подготовки / специальности)

Форма обучения: _очная_
        (очная, очно-заочная, заочная)

                    ОТЧЕТ                              (полужирный, 14)
          по лабораторной работе № N                    (полужирный)
   по дисциплине «НАЗВАНИЕ ДИСЦИПЛИНЫ»                  (метка полужирная)
   на тему: _«ТЕМА РАБОТЫ»_                             (значение подчёркнуто)

Обучающийся: _Фамилия Имя Отчество_
   (Фамилия Имя Отчество)                (подпись)      (9 пт)

Группа: _XXX-000_

Преподаватель: _Фамилия И. О._
   (Фамилия Имя Отчество)                (подпись)      (9 пт)

                 Москва 2026 г.                         (полужирный)
```

Раздел начинается с новой страницы (стиль Заголовка 1 сам переносит).

## 4. Структура отчёта по лабораторной работе

1. Титульный лист (раздел 3).
2. Разделы «N Задание N» (Заголовок 1, нумерация сквозная: 1, 2, 3...).
3. Внутри каждого задания пункты анализа идут по схеме:

```
Условие (текст задания, допускается курсив)
Код решения                (Courier New 10, серый фон)
Результат выполнения       (вывод R: Courier New 10, без фона)
Рисунки/таблицы            (см. раздел 5)
Гипотезы: H₀ — ...; H₁ — ...          (для статистических тестов)
Интерпретация: ...                     (полужирная метка + текст)
Вывод: ...                             (полужирная метка + текст)
```

4. Заключительный подраздел «Выводы» по всей работе (Заголовок 2).

## 5. Иллюстрации и таблицы (клон стиля ВКР)

- Рисунок вставляется **по центру** (ширина ~15,5 см), под ним подпись:
  `Рисунок N. Название` — по центру, **полужирно**, 14 пт, одинарный
  интервал. Разделитель — точка и пробел.
- **В тексте обязательна ссылка на каждый рисунок** — «(рисунок 3)»
  строчными, до или после самого рисунка.
- Подпись таблицы — ДВЕ строки над таблицей (как в ВКР):
  1) `Таблица N` — справа, полужирно, 14 пт;
  2) название — по центру, полужирно, 14 пт, с точкой в конце.
- **В тексте обязательна ссылка** — «(таблица 2)».
- Таблица: все границы ячеек одинарные (1/2 пт), шапка полужирная по
  центру 12 пт, текст ячеек 12 пт, одинарный интервал; у сводных таблиц
  добавляется итоговая строка («Итого»).
- Нумерация рисунков и таблиц — в пределах одного отчёта (отчёт = одна
  задача практикума).

## 6. Списки

- Маркированный: тире «–» с последующим пробелом (не маркер Word).
- Нумерованный: цифра с точкой «1. », набирается текстом.
- Перечисления внутри ответов: «a. », «b. » и т.д.

## 7. Генерация docx

### Вариант А — python-docx (без R, любой предмет)

```python
from synergy_docx import SynergyReport

r = SynergyReport(discipline="...", topic="...", lab_number=1,
                  group="ВБИо-403-рсоб")
r.heading("1 Задание 1. Название", 1)
r.paragraph("Условие...")
r.code("library(ggplot2) ...")        # код
r.output("... вывод R ...")           # результат
r.figure("output/plot.png", "Подпись")# рисунок + автонумерация
r.table([["A","B"],["1","2"]], caption="Название")  # таблица
r.hypotheses("средние равны", "средние различаются")
r.interpretation("p < 0,05 ...")
r.conclusion("...")
r.save("labs/lab-01/output/report.docx")
```

Пример запуска: `python templates/generate_report.py`.

### Вариант Б — R Markdown (для R-лабораторных, автоматические результаты)

В YAML-заголовке отчёта:

```yaml
output:
  word_document:
    reference_docx: reference.docx   # шаблон стилей из templates/
```

`reference.docx` собирается скриптом `python templates/build_templates.py`.

## 8. Состав результата практикума

По каждой задаче практикума оформляется **отдельный отчёт** — файлы
`Laboratornyiy praktikum N_Задача M_отчет.docx` и `.pdf` (pdf — конвертация
docx, например LibreOffice: `soffice --headless --convert-to pdf file.docx`).
