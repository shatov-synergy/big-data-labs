# ROADMAP — валидация лабораторных работ

Дорожная карта дополнительной валидации работ по дисциплине
«Продвинутые технологии работы с большими данными». Операционная
сводка: этапы, чеклист, статусы. Дословный первоисточник —
[`labs/lab-04/audit/protocol-zadacha1-apriori.md`](labs/lab-04/audit/protocol-zadacha1-apriori.md);
при расхождении формулировок приоритет у протокола.

## Текущая область валидации

**Лабораторный практикум 4, Задача 1 «Анализ потребительской корзины
(Groceries, Apriori)»** — единственный объект аудита по присланному
протоколу (12.11.2026). Срок LMS: практикум 4 — до 30.11.2026.

Вне области: Задача 2 практикума 4 (прогнозирование продаж), практикумы
1–3. Для них отдельные протоколы не присылались; audits добавляются
в этот roadmap по мере поступления протоколов.

## Режим работы

- Строго последовательные проходы 1→6; один проход — один ответ
  аудитора; после каждого прохода остановка до команды «Продолжай».
- Массовые проверки следующего этапа заранее не выполняются.
- Обязательное чтение правил до содержательного аудита: `AGENTS.md`,
  `templates/REPORT_STANDARDS.md`, правила `../synergy-agent`
  (жёсткие правила, sanitize/validate перед `itog/`).
- Доказательность: требование → файл/функция → данные → проверка →
  результат → вывод. Без выполнения кода воспроизводимость
  не заявляется; запрещены подгонка чисел, изменение оригиналов,
  commit/push без разрешения.
- Статусы проходов и чеклиста обновляются в этом файле после каждого
  прохода; замечания переносятся по ID.

## Реестр замечаний

Формат записи (из протокола): ID / проход / критичность / файл-функция-строка /
источник требования / наблюдаемый факт / AI4-процедура / метод проверки /
доказательство / влияние / минимальное исправление / способ повторной
проверки / статус.

Критичность:

- **критическое** — центральный результат недостоверен, невоспроизводим
  или нарушено центральное требование;
- **существенное** — затронуты интерпретация, алгоритм или комплектность;
- **незначительное** — локальная неточность без изменения основного вывода;
- **улучшение** — сверх обязательных требований.

Замечание закрывается только повторной проверкой.

## Статусы проверки

подтверждено выполнением; подтверждено статически; частично подтверждено;
не подтверждено; обнаружено несоответствие; не проверено (нет материалов);
не проверено (ограничение среды); неприменимо. «Не проверено» ≠ «ошибка».

## Итоговый вердикт (Проход 6)

Один из: готово к сдаче; готово после незначительных исправлений;
требуется существенная доработка; недостаточно данных для заключения.
Безусловное «готово» не выдаётся при непроверенных существенных
требованиях.
