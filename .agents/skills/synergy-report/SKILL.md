# Скилл: отчёт в стандартах Синергии

Полная спецификация — `templates/REPORT_STANDARDS.md` (читать целиком).
Здесь — контрольный минимум для сверки/сборки.

## Чек-лист сверки (каждый отчёт)

**Титульный лист** (клон ВКР, безрамочные формы-таблицы, значения
подчёркнуты нижней границей ячейки):
- [ ] Шапка: «НЕГОСУДАРСТВЕННОЕ ОБРАЗОВАТЕЛЬНОЕ ЧАСТНОЕ УЧРЕЖДЕНИЕ ВЫСШЕГО
      ОБРАЗОВАНИЯ» + полужирная «МОСКОВСКИЙ ФИНАНСОВО-ПРОМЫШЛЕННЫЙ
      УНИВЕРСИТЕТ «СИНЕРГИЯ»»
- [ ] «Факультет Информационных технологий» — значение подчёркнуто, 15 пт
- [ ] Форма: «Направление подготовки: 09.03.02 Информационные системы и
      технологии» и «Кафедра ИИиАД» подчёркнуты, под ними курсивные
      подсказки 10 пт «(код, наименование)» / «(аббревиатура)»;
      «Профиль: …» подчёркнут на всю ширину
- [ ] «ОТЧЕТ ПО ЛАБОРАТОРНОЙ РАБОТЕ № N» — 16 пт полужирный
- [ ] «по дисциплине «…»» полужирно; «на тему» — тема подчёркнута полужирно
- [ ] Участники: Обучающийся/Группа/Преподаватель — ФИО полужирным
      курсивом, подсказки 8 пт «(Фамилия Имя Отчество)» «(подпись)»
- [ ] Внизу: «МОСКВА 2026 г.» полужирно, год подчёркнут
- [ ] Титульник занимает ровно одну страницу

**Тело**:
- [ ] TNR 14, полуторный интервал, по ширине, красная строка 1,25 см
- [ ] Заголовок 1: 16 пт полужирный, по центру, с новой страницы
- [ ] Заголовок 2: 14 пт полужирный, по центру
- [ ] Код: Courier New 10, серый фон #F2F2F2; вывод R: Courier New 10 без фона
- [ ] Каждый рисунок РОВНО ПО ЦЕНТРУ (без красной строки), под ним
      «Рисунок N — Название» полужирно по центру (тире по ГОСТ 7.32-2017)
- [ ] Перед каждой таблицей: «Таблица N — Название» одной строкой слева,
      без отступа, полужирно
- [ ] В тексте есть «(рисунок N)» и «(таблица N)» для КАЖДОГО объекта
- [ ] У статистических тестов: «Гипотезы: H₀ — …; H₁ — …», «Интерпретация: …»,
      «Вывод: …»
- [ ] Все числа — фактические результаты расчётов (inline-R)
- [ ] Есть раздел «Выводы» по работе

## Сборка без R (python-путь)

Когда R не нужен (теоретические предметы):

```python
from synergy_docx import SynergyReport   # templates/synergy_docx.py
r = SynergyReport(discipline="...", topic="...", lab_number=2, group="ВБИо-403-рсоб")
r.heading("1 Название раздела", 1)
r.paragraph("...")
r.code("..."); r.output("...")
r.figure("путь.png", "Подпись")          # автонумерация «Рисунок N.»
r.table([["A","B"],["1","2"]], caption="Название")
r.hypotheses("...", "..."); r.interpretation("..."); r.conclusion("...")
r.save("labs/lab-NN/output/Отчет.docx")
```

PDF — конвертацией docx (см. скилл render-reports, шаг 3).
