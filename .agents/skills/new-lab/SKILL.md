# Скилл: новая лабораторная работа

Исходные данные: номер практикума N (например 2), текст заданий (docx/фото/текст),
при необходимости — код скриптов.

## Шаги

1. **Задание в репозиторий**: сохранить присланные файлы задания в
   `assignments/lab-NN/` (docx как есть; фото/текст — предварительно извлечь
   содержимое и при необходимости сохранить оригинал рядом).

2. **Структура**: создать каталоги
   ```
   labs/lab-NN/output/
   labs/lab-NN/taskM_<тема>.R        # по одной заготовке на задачу
   labs/lab-NN/zadachaM_report.Rmd   # отчёт по каждой задаче
   ```
   и скопировать свежий `templates/reference.docx` в `labs/lab-NN/`
   (если templates пересобирались после последнего коммита — сначала
   `python templates/build_templates.py`).

3. **Скрипты задач**: писать по присланному коду преподавателя максимально
   дословно; допускаются только технические правки:
   - `install.packages(...)` → гвард `if (!requireNamespace(...)) install.packages(...)`
     или проверка по списку `installed.packages()`;
   - сохранение графиков: `ggsave("output/<task>_<имя>.png", ...)`,
     интерактивных plotly — `htmlwidgets::saveWidget(as_widget(p), "output/<имя>.html", selfcontained = TRUE)`;
   - кэш внешних данных в `data/` (как `task3_tesla.R` — `data/tsla.csv`):
     «есть кэш → читаем, нет → скачиваем и пишем»;
   - явная ошибка `stop()` при недоступности данных, не тихий пропуск.

4. **Отчёты**: для каждой задачи — `zadachaM_report.Rmd`, скопировав
   титульный блок и YAML из `labs/lab-01/zadacha1_report.Rmd`
   (output: word_document + reference_docx: reference.docx, knit → output/).
   В заголовке темы заменить номер задачи и название. Правила текста —
   в `templates/REPORT_STANDARDS.md` (разделы 4–6): условие, ход решения,
   ссылки «(рисунок N)»/«(таблица N)», Гипотезы/Интерпретация/Вывод,
   общий вывод по работе. Числа — только inline-R из расчётов.

5. **Прогон и сдача**:
   ```bash
   docker compose run --rm rstudio bash -lc "cd labs/lab-NN && Rscript task1_....R"
   # затем рендер и pdf — см. скилл render-reports
   ```
   Файлы сдачи: `Laboratornyiy praktikum N_Задача M_отчет.{docx,pdf}`.

6. **Коммит**: `git add -A && git commit -m "Лабораторная работа N: скрипты и отчёты"`.

## Проверка

- Каждый скрипт проходит headless без ошибок.
- Каждый отчёт: postcheck 0 ошибок, визуально — титульник-форма,
  полужирные подписи, двухстрочные «Таблица N».
- В отчётах заполнены все числа, ФИО преподавателя оставлено подчёркнутым
  полем (заполняет обучающийся).
