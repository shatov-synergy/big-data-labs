# Реестр исключений image-guard

Порядок ведения — см. скилл `image-guard` (шаблон
`.agents/skills/image-guard/scripts/image-guard-exceptions.md`).
Каждое исключение: id, причина, область действия, дата пересмотра.

## EXC-2026-11-12-01 — linux-libc-dev в big-data-labs-rstudio

- **CVE**: 52 идентификатора из `.trivyignore` (CVE-2026-53398,
  CVE-2026-63825 … CVE-2026-98805), все — пакет `linux-libc-dev`.
- **Причина**: `linux-libc-dev` — заголовки ядра Linux для компиляции;
  код ядра из образа в контейнере не исполняется (контейнеры работают на
  ядре хоста; здесь — WSL2 6.18.33, обновляется вне образов). Класс
  ложных срабатываний сканеров контейнеров. Агрегация по PkgName
  (12.11.2026; повторная агрегация 13.11.2026 — +10 новых ID того же пакета): других пакетов с CRITICAL в образе нет.
- **Область**: образ `big-data-labs-rstudio:latest` (и его пересборки на
  базе rocker/rstudio:4.6.1 / Ubuntu noble) в учебном репозитории
  big-data-labs; сервис слушает 127.0.0.1:8787.
- **Дата пересмотра**: 2027-02-12 (или при смене базового образа).
