# Аннотация. Лабораторный практикум 3 | Тема 2. Методы очистки и предобработки данных

Дисциплина «Продвинутые технологии работы с большими данными»,
Университет «Синергия». Выполнено 8 ноября 2026 г.

## Постановка задачи

На данных о ценах на жильё и социально-экономических характеристиках
районов Москвы построить и сравнить пространственные эконометрические
модели: OLS → тест Морана на остатки → LM-тесты → SAR (`lagsarlm`) и
SEM (`errorsarlm`) → сравнение по AIC/BIC → интерпретация эффектов.
Перед моделированием — очистка и предобработка данных о квартирах
(DATA.xlsx) и данных о метро (METRO.xlsx), привязка к полигонам районов
(export.geojson, OpenStreetMap).

## Что сделано

1. **Очистка данных** (`labs/lab-03/task1_cleaning_geo.R`): из
   25 877 объявлений после контроля типов, пропусков и удаления
   выбросов по 1/99-перцентилям сохранено 24 713 (95,6%); 1 160
   выходов метро проверены на пропуски координат; из 262 геометрий
   GeoJSON отобрано 132 полигона районов (`admin_level=8`) с
   нормализацией названий.
2. **Пространственная привязка**: `st_join(st_within)` + до привязка
   вне полигонов к ближайшему центроиду (449+443 граничных случаев);
   расстояние до ближайшего метро по формуле гаверсинусов; агрегирование
   ~30 показателей по 128 районам (фильтр n ≥ 10).
3. **Диагностика**: матрицы весов k-NN (k=8) и Queen (в среднем 5,3
   соседа, изолированных нет); глобальный Моран I = 0,559 (Queen,
   p < 1e-23) — сильная автокорреляция цен; LISA: 26 кластеров
   High-High (центр), 14 Low-Low (периферия), 32,3% значимых районов.
4. **Модели** (`labs/lab-03/task2_spatial_models.R`): VIF-контроль
   (исключён `share_skyscraper`, VIF 10,9); OLS c 16 факторами →
   пошаговый отбор по AIC → финальная модель из 4 факторов
   (R² = 0,688); тест Морана на остатки I = −0,061 (p = 0,788);
   LM-тесты: LMlag p = 0,292, LMerr p = 0,628, RLMlag p = 0,071,
   RLMerr p = 0,122; SAR (ρ = 0,044; LR p = 0,624) и SEM
   (λ = −0,173; LR p = 0,250); сравнение: AIC OLS 180,5 < SEM 181,2 <
   SAR 182,3 (BIC аналогично); эффекты SAR: косвенные ≈ 5% общих.
5. **Отчёт по ГОСТ 7.32-2017**: 19 страниц, титульный лист-форма
   «Синергии», СОДЕРЖАНИЕ с фактическими номерами, ВВЕДЕНИЕ, разделы
   1–3, ВЫВОДЫ, СПИСОК ИСТОЧНИКОВ, 7 рисунков (карты цен, LISA,
   остатки моделей, AIC, эффекты) и 5 таблиц.

## Главный результат

**Пространственная автокорреляция цен на жильё Москвы полностью
объясняется наблюдаемыми характеристиками районов.** Сырые цены сильно
кластеризованы (Моран I = 0,56), но после включения в OLS-регрессию
структуры рынка и типажа жилья (доля вторички −2,67 лог-пунктов на
единицу доли, p < 0,001; доля студий +1,49, p < 0,001; средняя площадь
−0,0085, p = 0,013) остатки пространственно независимы: тест Морана и
LM-тесты незначимы, параметры ρ и λ не отличаются от нуля, а
информационные критерии AIC и BIC отдают предпочтение классической
OLS-модели. Косвенные (межрайонные) эффекты в SAR составляют лишь ~5%
общих. Практический вывод: сегрегация дорогого и дешёвого жилья в
Москве — это пространственная кластеризация характеристик объектов
(вторичка/новостройки, студии, доступность метро), а не переливы цен
между соседними районами; для ценообразования значимы состав
предложения и тип жилья, поправка на пространственные лаги не требуется.

## Воспроизведение

```bash
docker compose up -d --build          # образ big-data-labs-rstudio
docker compose run --rm rstudio bash -lc \
  "cd labs/lab-03 && Rscript task1_cleaning_geo.R && Rscript task2_spatial_models.R"
# отчёт: rmarkdown::render("otchet.Rmd") + templates/apply_title_page.py
```

Технические правки относительно методического скрипта преподавателя
(задокументированы в шапках скриптов): чтение данных из `data/`,
`ggsave()` в `output/`, фильтр полных наблюдений до `step()` (иначе
«number of rows in use has changed»), добавлен отсутствующий вызов
`impacts()`, исправлена ошибка смещения меток в таблице эффектов
(`impacts()` не включает свободный член, а метки в исходнике брались с
ним), сохранение всех результатов в rds/csv.
